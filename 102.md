⭐️ How a code or function is executed in C language ?
🟡 Rules to follow always whenever want to see code execution in C language :
📀 Whenever a function call happens then always us function ki ek frame banti hai Stack memory me                       and control goes to that function .
📀 Whenever a function is done executing wo frame stack memory se erase ho jaati hai yaani memory 
clean up and control returns back to the function from where that call is happened .
📀 Ek function me bane hue variable local variables hote hai yaani un variables ko hum bahar access nahi kar sakte hai.
📀 In C programming , only stack memory (not heap memory) is used for function calls and local variables .

# Important point
When we run our compiled code yaani runtime par kya hota hai ki , sabse pehle OS RAM me code ki pura machine code load karta hai and then wo code 2 parts me divide hota hai , 1st ki function ke andar likha hua code and 2nd is function ke bahar likha hua code , dono ki type ke code ka execution alag types se hota hai , but both in two steps :
1. RAM memory allocation
2. Code Execution


1. RAM memory allocation
Is phase me kya hota hai , ki jitne bhi global variables(isi ko function ke bahar ka code kehte hai) hai , unki sabse pehle RAM me memory reserve hoti hai when we load our code in RAM, yaani sirf ek empty memory layout banta hai RAM me, jisme empty memory blocks reserve hote hai sirf global variables ko , abhi tak usme value nahi gayi hai un global variables ki , only space reserve hui hai. Remember, yaha local variables ka memory reservation nahi hota hai . (Local variables ek function ke andar hote hai and in variables ka memory reservation and value allocation real time me hota hai jab wo function ka code run hota hai line by line , will see in phase 2) . Intotal, RAM memory allocation me function ke bahar waale code which means global variables declaration yaa global code , unke liye RAM me memory reserve ho jaati hai code execution se pehle hi but local variable yaani function ke andar ka code ke liye memory allocation code execution se pehle nahi hota hai .

2. Code Execution
Is phase me ab jo machine code load hua tha wo instruction line by line CPU me jaate hai and execute hote hai but for a global variable or code it is different and for a function(yaani local variable) it is different . 

Toh jab ek global variable declaration code chalta hai toh like int a = 5 {a is a global variable} . Toh yaha kya hoga CPU me ki sabse pehle MU yaani Memory Unit chalega and yeh line of code MU me store hoga and then uske baad CU yaani Control Unit chalega jo kya karta hai ki us line of code ka matlab samjhega and use do parts me classify karega ki : 1st Kya us code se variable declaration yaa Koi function call ho raha hai kya and 2nd is ki kya wo code se koi calculation ho rahi hai kya yaani kya us instruction me koi operator use hua hai kya and agar 1st Case hai toh CU khud hi us variable ko declare kar dega yaani memory allocate karke usme value daal dega(Local Variable Case) yaa RAM me reserved memory me value daal dega(Global Variable Case) but agar calculation yaani koi logical operation hue toh CU control de dega AU yaani Arithmetic-Unit ko , jo kya karega ki us calculation ko karke jo bhi result aayega wo return kar dega and this is how a global code ka execution takes place . Yaani, simply int a = 5 ko MU me store karo and then CU jo RAM me reserved memory "a" hai usme 5 daal dega .

Yaani, simply when function is called then ek memory area reserve hoga for that function and then line by line code execute hoga and agar variable declaration ka code hoga like int t = 6 (local variables ka)  toh wo real time me memory reservation and value allocation hogi in that memory .

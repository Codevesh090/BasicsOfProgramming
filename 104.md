🟡 How to take string input from user ?
📀 Hum scanf() ka use nahi karte hai multiword string input karne ke liye .
📀 scanf() can take multi-characters at once as input but it is incapable of taking multi-word string .
📀 scanf(%s,str) se string input lene ke liye hum    %s    and     "name of the string"    as argument paas karte hai .
📀 It is because scanf() uses space , tab , /n newline as delimiters yaani scanf() jaise hi encounter karega koi   "space" , "tab" yaa "newline" character wo wahi input lena rok dega . Let say user ne input me diya               "Hello my name is Devesh" . Toh scanf() sirf "Hello" hi input me le paayega and then wo jaise hi " " space encounter karega, wo wahi ruk jaayega and aage nahi badega . Isiliye scanf() sirf ek word input me le sakta hai, multiword nahi .
📀 scanf() ka main kaam hai variety of data ko input karna, It can input multiple variety of data using %d , %s etc...
📀 Also,scanf() se hum multiple differnt inputs ko ek saath le sakte hai     like:     scanf("%d %d %d",a,b,c)
Example : [Intotal,scanf(%s,name-of-array) can only take single word input due to its delimiters ](/Images/101-81.png)

Toh isi problem ko solve karne ke liye aaya : Ek predefined function ->  gets() function
gets() - Is function ka sirf ek hi kaam hai , ki multiword string ka input lena .
       - gets() ka delimiter sirf /n newline hoti hai . Yeh newline character keyboard par Enter dabane se create hota  hai and agar user ne 1st line likhi and Enter dabaya and then 2nd line likhi toh gets() sirf 1st line ko hi input me lega 2nd line nahi as Enter dabane par /n aagaya and /n toh gets() ka delimiter hai .  
       - gets() "space" and "tab" dono ko ek string ka hi part maanta hai .
       - Example : [](/Images/101-82.png)

       🟢 Important Point : gets() function depretiate ho chuka hai , ab hum iska use nahi karte hai and yeh depreciate isliye hua hai kyuki     "Isme bhi wahi bound-checking waali problem hai"      Yaani agar hum ek string declare karte hai like      char str[10];     and ab Input me user deta hai "Hello I am devesh" Toh isme more than 10 characters hai (Remember : Don't just count words - "space bhi ek char hai") 
       Toh yeh gets() kya karega ki is pure input ko le lega and jo 30 charcters hai unhe toh reserved space me rakh dega but usse jyada jo extra characters aa rahe hai unhe yeh kya karega ki uthkar unreserved area me daal dega which is not approtiate and unsafe as we know .

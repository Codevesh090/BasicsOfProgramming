---------------------------------------The full process How a calculator software runs on computer
Developer writes code
        ↓
Compiler creates executable
        ↓
calculator.exe stored on SSD
        ↓
User double-clicks
        ↓
OS creates process
        ↓
OS loads program into RAM
        ↓
CPU fetches instructions from RAM
        ↓
CPU executes instructions
        ↓
Program asks OS for window
        ↓
OS talks to GPU
        ↓
GPU draws pixels
        ↓
Monitor shows Calculator
        ↓
User clicks button
        ↓
OS sends event
        ↓
Calculator handles event
        ↓
CPU calculates result
        ↓
GPU redraws screen
        ↓
User sees answer
